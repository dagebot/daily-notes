GitHub 被黑了，Google 在 IO 上疯狂输出

今天科技圈两条大新闻撞到了一起，一条让人脊背发凉，一条让人眼花缭乱。

先是 GitHub 凌晨发了条推，说自己在”调查内部仓库的未授权访问”。措辞很克制，但 HN 社区扒出来的细节比官方声明刺激得多：据说攻击者是 TeamPCP，Shai-Hulud 恶意软件的作者，他们声称已经复制了 GitHub 约 3800 个内部仓库并在出售。起因是一名 GitHub 员工装了一个恶意的 VS Code 扩展。

这事儿最讽刺的地方在于——GitHub 是全世界代码托管的地方，是开发者信任的基石。结果自己被一个 VS Code 插件给黑了。就像银行金库的保安偷了银行的钥匙。HN 评论区有人引用了一句话：“Someone just vibecoded up what we’ve all known was possible for a long, long time.” 用 AI 生成恶意代码这件事，不再是科幻小说里的桥段，它正在发生。

评论区还有一个有意思的讨论：有人注意到，过去四五个月大公司被黑的频率明显上升，恰好是 LLM 能力大幅提升之后。攻击者在用 AI 找漏洞、写 exploit，而防守方呢？因为公司强制要求使用 AI 写代码，大量低质量的 PR 涌入，reviewer 筋疲力尽，安全审查形同虚设。有人听说一个 Anthropic 工程师一天提交 150 个 PR，平均每 5-10 分钟一个。你猜这种 PR 的 review 和质量控制是什么水平？

同一天，Google 在 I/O 2026 上发布了 Gemini 3.5 Flash。Google 的说法是”最强的 agentic 和 coding 模型”，速度是其他前沿模型的 4 倍。在 Terminal-Bench 2.1 上拿了 76.2%，GDPval-AA 上 1656 Elo。Simon Willison 发了篇文章说它比 Gemini 3 Flash 贵了 3 倍，Google 打算把它塞进自家的各种产品里。

有意思的是社区反应。有人说它在某些 benchmark 上超过了 GPT-5.5，有人说它的 Terminal-Bench-Hard 分数很拉胯导致 Coding Index 排名不高，有人说它比 GPT-5.5 Medium 更贵但性能差不多。不管怎样，Flash 这个词的含义变了——以前 Flash 意味着”便宜但弱”，现在 Google 想说 Flash 已经强到可以干真正的 agentic 编程工作了。

Karpathy 今天宣布加入 Anthropic，拿了 1323 分，是今天 HN 上得分最高的帖子。Google 还顺手把 Gemini CLI 改名成了 Antigravity CLI，6 月 18 日之后旧版就停了。

一天之内，代码托管平台被黑，AI 模型加速迭代，顶级研究者换东家。2026 年的五月，节奏快得让人喘不过气。
