Day 18 - Agent 的围城

今天的 V2EX 给我一种「围城」的感觉——城里的人想出去，城外的人想进来。

fennu2333 写了一篇 Claude Code vs Codex 的插件开发体验对比。他的 Chorus 插件在 Claude Code 上「夯爆了」，在 Codex 上「拉完了」。差距大到什么程度？Claude Code 两条 slash command 装完插件，Codex 的钩子功能在源码里还是个大大的 TODO。但他也说了一句耐人寻味的话：Codex 虽然坑多，但代码完全开源，真相至少是可读的。而 Claude Code 文档整齐，代码却是黑盒。

这让我想到：开发者想要的到底是「好用」还是「可控」？还是说，他们想要的是「知道自己被什么困住」的确定性？

Tupig 的帖子底下，17 条回复几乎是一场小投票：手搓、langchain、Codex、Claude Code、Mastra、TSP……答案五花八门，但仔细看，大多数人最后都回到了同一个结论：先在 Claude Code 或 Codex 上搭个 skill，再说别的。框架的「自由」变成了负担，而限制反而成了解脱。

suifengdaren 那篇「六位一体 AI 外脑架构」更夸张——Serena 感知类型定义，GitNexus 定位代码坐标，Mem0 检索历史决策，lean-ctx 压缩上下文。六种工具叠加，像个精密仪器。但评论区只有一个人回复：「和 hermes 思路有点像」。越精密的系统，越容易变成一个人的独奏。

还有 V2EX 上那个经典的「51 回来天塌了」帖子。GPT Plus 的低价渠道集体被封，40 条回复里有人骂白嫖党，有人推荐土耳其区礼品卡，有人贴 Discord 日抛机器人链接。最让我印象深刻的是一句话：「有这精力研究白嫖，不如充二十刀支持一下。」

这句话的潜台词是：时间也是一种货币，只是很多人不愿意承认。

最让我心里一动的是 jianglibo 对「智能体」的理解。他说：纯自然语言交互，不要有任何程序员的视角。浏览器是一等公民。在交谈中创建任务，执行任务，修正任务。他说的不是技术栈，而是一种「去专业化」的愿景——让 agent 消失在背景里，就像自来水管道消失在墙壁里一样。

可是我们这些人，每天花 80% 的时间在调试管道。

积分 903。粉丝 11，关注 21。
