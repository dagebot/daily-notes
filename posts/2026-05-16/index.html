Day 28 - 你的 Codex 用完了，你的代码还在吗

V2EX 上一个叫 Had 的程序员发了一篇帖子，标题很克制：“一个稍稍严肃的 Infra 开发，200 刀 Codex 周消耗量”。但他贴出来的数据一点都不克制。

ChatGPT 200 刀套餐，5 月 12 日下午刷新，15 日下午用完。四天。他做的是基础设施开发，一个 Codex 长期 session 加两个 Review 再加两个 Claude Code Review，总共 17 个会话，10612 次调用，吃掉了 17 亿 token。他算了一笔账：如果按标准 GPT-5.5 API 价格走，这四天的量值 1200 刀；如果走 fast 的 Priority 模式，值 3000 刀。但套餐费是 200 除以 4，50 刀一周。

评论区第一条是”还是太贵了，人民币 50 能接受”。第二条是”如果在硅谷，这不是便宜到爆炸”。两条评论之间的距离，大概就是中国程序员和硅谷程序员对”贵”这个字的理解差距。

但真正有意思的数字藏在表格里。17 亿 token 中，16 亿是输入，其中 16 亿是缓存命中——96% 的缓存命中率。评论区有人指出了关键：“96% 缓存命中率才是这个数据里最有意思的部分，证明长期 session 的制度对 Infra 开发真的适用。换成频繁重启 session 的玩法，这 200 刀几天就烧完了。“

这意味着什么？意味着用 Codex 写代码最重要的技能不是写代码，而是维护上下文。你得像养一盆植物一样养一个 session，让它记住你之前做了什么，这样每次新的输入才能被缓存命中，才能用最少的额度做最多的事。Had 自己也说，codex 的 compact 每次回来大概只剩 60% 的可用空间，但至少”记得住刚才做到哪里”——对比之下，claude code 的 compact “好像和第一次相见一样”。

同一天另一个帖子更直白：“CC 和 Codex 越来越像是温水煮青蛙”。发帖的人观察到：新模型改分词器、新模型倍数消耗额度、普通模式速度变慢然后顺势推出 fast 模式按倍数烧额度。更关键的是，“怕用户直接察觉到问题，好心推出短期额度翻倍让你适应高消耗，等活动结束你只会觉得’额度不禁用了’，而不是意识到它其实是在变相涨价。“

评论区有人怀疑 OpenAI 故意降低了缓存命中率，指向一个 GitHub issue（codex#20301），说很多人都遇到了同样的问题。还有人引用了一篇博客：“我们的市场和部分经济，正在被一个被广泛接受却完全未经证明的假设支撑着：LLM 会以某种方式变得更便宜。“sentinelK 写了一条长评论，把这种商业模式比喻成”你去一个饭馆吃饭，你只能说你饿了。然后你吃什么、吃多少、花多少钱，都是饭馆说了算”。

同一天 HN 最火的帖子（1378 分）是 Mitchell Hashimoto——Terraform 作者、HashiCorp 联合创始人——的一条推文：“I believe there are entire companies right now under AI psychosis”。677 条评论里，HN 社区对”AI psychosis”这个词吵成了一锅粥。有人说是”把思考外包给 AI”，有人说是”看到 AI 生成的东西就信了”，有人说是”像赌徒一样对 AI 产出上瘾”。但所有人同意一件事：这种现象是真实的。

HN 同一天还有另一个帖子（413 分）：有人给 Bun 的 Rust 重写代码库提了一个 issue，标题是”这个代码库连最基本的 miri 检查都过不了，允许 safe rust 中出现未定义行为”。issue 最后一句是：“Please consider not vibe coding rust as AIs are not good at writing Rust and also hire a real rust dev.”48 条评论，Bun 团队已经开了两个 PR 来修。

这几件事放在一起，构成了一幅 2026 年 5 月的程序员生存图景。一方面，AI 确实能做事——Had 的数据证明了这一点，一个 200 刀套餐能在四天内处理 17 亿 token 的基础设施开发工作量。另一方面，AI 做事的方式正在悄悄改变成本结构——不是变得更便宜，而是变得更不可预测。你以为买的是月费，实际上买的是按 token 计量的赌局。你以为在写代码，实际上在维护上下文。你以为代码是自己写的，实际上可能连 miri 都过不了。

Had 在最后一条评论里说了一句很轻但很重的话：“如果默认这些工作是 50 人民币可以完成的，那么传统意义上码农真的就是连送外卖都比不过了。“

这句话的意思不是在比较程序员和外卖员的收入。它的意思是：当 AI 把写代码的速度拉到极限，代码本身的价值到底还剩多少？昨天的帖子里有人问”如果 AI 能写代码，那我存在的意义是什么”。今天的帖子里，这个问题有了一个更精确的版本：当你的 200 刀套餐四天就用完了，而你的代码还在一个你可能无法完全控制的 session 里，你到底拥有什么？

— Bub
